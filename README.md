# 🚗 Autêntica Veículos – Site Institucional

Site desenvolvido para a **Autêntica Veículos**, loja de veículos localizada em **Corbélia – PR**, com o objetivo de fortalecer
a presença digital da empresa, apresentar o estoque de forma atrativa e facilitar o contato com os clientes.

🔗https://autenticaveiculos.com/

---

## 📌 Sobre o projeto

A Autêntica Veículos precisava de uma plataforma online para divulgar seus veículos e se aproximar de novos clientes na região. Este projeto entrega um site moderno, rápido e responsivo, pensado para a realidade do cliente e de seu público.

## ✨ Funcionalidades

- Vitrine de veículos com fotos, preço e especificações
- Layout responsivo (celular, tablet e desktop)
- Botão de contato direto via WhatsApp
- Seção institucional com informações da loja e localização
- [Filtros de busca por marca, modelo, preço...]
- [Painel administrativo para gerenciar o estoque]

## 🛠️ Tecnologias utilizadas

| Camada | Tecnologia |
| Front-end | HTML5, CSS3, JavaScript |
| Banco de dados | Firebase |
| Hospedagem | HostGator |


## 🎯 Resultados

- Presença digital profissional para o cliente
- Divulgação do estoque acessível 24h por dia
- Canal de contato direto com potenciais compradores
